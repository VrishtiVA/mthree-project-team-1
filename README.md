## Set Up & Running Instructions

### Backend Application

1. Open the backend application in IntelliJ.
3. Run the backend application in IntelliJ. The application will generate the database by itself in create-drop mode, thanks to ddl-auto and our Spring JPA set-up.

### Frontend Application

1. Ensure node.js is installed, as required by react.
2. Open the frontend application directory.
3. Install the node modules with `npm install`.
4. Start the frontend application with `npm start`.
5. Give the application a moment to start up at localhost port 3000.
